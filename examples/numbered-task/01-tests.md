# Задача: Написать unit-тесты

**Статус:** ✅ Выполнено
**Приоритет:** Высокий
**Зависимости:** Нет

## Обоснование

В вымышленном проекте нет тестов, из-за этого страшна любая правка.

## Что сделать

1. Создать `tests/` на уровне проекта.
2. Написать тесты для модулей без внешних зависимостей.
3. Подготовить фикстуры: примеры кадров и конфигов.
4. Настроить `pytest` в `pyproject.toml`.

## Критерий готовности

```bash
pytest tests/ -v --cov=acme
```

Все тесты проходят, покрытие не ниже 70% на ключевых модулях.
