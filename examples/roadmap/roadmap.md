# acme-scanner — roadmap регистратора

Вымышленный проект для демонстрации формата. Показывает статусы фаз, зависимости и acceptance criteria.

## Goal

Собрать поток сообщений от устройства, разобрать его инкрементально и отдать в UI без блокировок.

## Scope

- **In scope:** приём, разбор, транспорт, тесты.
- **Out of scope:** визуализация (отдельный roadmap).

---

## Phase 1: Генератор потока — DONE

**Status:** Done (сборка и запуск проверены).

### Tasks

1. **Сделать воспроизводимый генератор сообщений** — DONE
2. **Добавить headless-режим** — DONE

### Dependencies

- None

### Acceptance criteria

- [x] Генератор держит 25 сообщений в секунду.
- [x] Headless-прогон длится 60 секунд без потерь.

## Phase 2: Инкрементальный парсер

**Status:** in progress (базовый разбор готов).

### Tasks

2. **Сохранять недособранный хвост буфера** — DONE
3. **Замерять бюджет на сообщение** — в работе

### Dependencies

- Phase 1

### Acceptance criteria

- [x] Хвост буфера переносится между вызовами.
- [ ] Бюджет укладывается в 40 мс на сообщение.
